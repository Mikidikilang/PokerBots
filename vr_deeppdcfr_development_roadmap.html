2
Phase 2
Buffer architecture
vr_buffers.py
›
Goal
Implement the bifurcated buffer design that is the architectural keystone of VR-DeepPDCFR+. The ephemeral advantage buffer must be cleared at the start of every iteration — this is non-negotiable for convergence. The persistent strategy buffer must use tᵞ (γ=2) time-decay insertion weights.
Three buffer classes
B_V
EphemeralAdvantageBuffer
Simple list. clear() called at iteration start. Capacity bounded by K × max_tree_depth. Stores (obs, legal_mask, r̄)
B_Π
PersistentStrategyBuffer
Reservoir sampling with t² insertion weights. Mini-batch sampling proportional to stored weight. Stores (obs, σᵗ, t)
B_Q
ValueBaselineBuffer
Uniform reservoir sampling. Stores complete trajectory tuples (h, â, û, I') for Expected SARSA Q-network training
Discard from legacy
RolloutBuffer (PPO) RegretBuffer (persistent reservoir)
Critical invariant
After EphemeralAdvantageBuffer.clear(): len(buffer) == 0 and all stored tensors are freed. Verified by asserting GPU memory delta ≈ 0 post-clear on a full-tree traversal.

Phase 3
Neural network architecture
vr_networks.py
›
Goal
Replace the PPO actor-critic with four specialized networks, each with a distinct loss function and training data source. All four share a common observation encoder backbone.
Four network classes
θ
CumulativeAdvantageNet
Wide MLP 3-4L × 512-1024h + LayerNorm. Output: ℝ^A. Loss: MSE(θ_t, relu(θ_{t-1}×decay + r̄)). Trains on B_V after clear.
φ
InstantaneousAdvantageNet
Identical arch to θ. Output: ℝ^A. Loss: MSE(φ_t, r̄). Trains ONLY on current-iteration data — eliminates one-iteration lag.
Q
HistoryValueBaselineNet
Maps (h, â) → scalar. Trained via Expected SARSA: y_Q = û + γ_Q × Σ_a' σ(a'|h') Q(h', a'). Source: B_Q.
Π
AverageStrategyNet
Softmax output. Loss: Σ_t t² × MSE(Π(obs), σᵗ). Behavioral cloning weighted by iteration index. This is the deployable policy.
Predictive strategy formula
σ = regret_match(max(θ_{t-1}(obs) × decay + φ_{t-1}(obs), 0))
decay = (t-1)^α / ((t-1)^α + 1), α=2

CardEmbedding ContextEmbedding _build_mlp() LSTMHistoryEncoder
Validation gate
All four network forward passes produce correct output shapes on dummy data. No NaN in any loss. Gradient flow confirmed through each loss independently. θ and φ produce distinct outputs (not identical — verifies separate parameter sets).

Phase 4
VR-DeepPDCFR+ engine
vr_deep_pdcfr_engine.py
›
Goal
Implement the core per-iteration CFR loop. Every step must execute in the exact order below — deviation from this sequence invalidates the mathematical guarantees.
Per-iteration sequence (strictly ordered)
①
Clear B_V,i for each player
Non-negotiable first step. Any data from t-1 surviving into t corrupts temporal discounting math
②
K external-sampling traversals per player
At each node: compute predicted σ from frozen θ_{t-1} + φ_{t-1}; compute r̄ = A_net[a] − Q(h,σ); insert (obs, mask, r̄) into B_V,i; opponent samples one action and recurses
③
Update θ_t (cumulative advantage)
Freeze θ_{t-1}; apply decay scalar; apply CFR+ clip: y_cum = relu(scaled + r̄); MSE(θ_t(obs), y_cum.detach())
④
Update φ_t (instantaneous advantage)
MSE(φ_t(obs), r̄.detach()) on same B_V,i data — pure current-iteration signal, no carry-over
⑤
Update ω_t (Q baseline)
Sample trajectory tuples from B_Q; apply Expected SARSA targets; update Q network
⑥
Accumulate into B_Π with weight t²
Store (obs, σᵗ, t) — iteration t=1000 carries 100× more weight than t=10
⑦
Update Π_ψ (average strategy)
Weighted MSE against stored strategy distributions. This is the policy that ships to RTA
Reuse from legacy
MCCFRTraversal (state save/restore) WorkerPool SharedMemoryRegretBuffer
Validation gate — Kuhn Poker first
After 1000–2000 iterations on kuhn_poker_minimal.py, the trained Π network must produce: Jack → bet ~1/3 of the time, Queen → never bet, King → always bet. Any deviation indicates a buffer ordering bug, a network wiring error, or incorrect discounting. Do not proceed to 6-max until Kuhn Poker converges.
